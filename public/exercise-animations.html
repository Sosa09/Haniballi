2.5D Animation Prototype

Since AI generates high-quality static images, the most elegant and lightweight way to "animate" them in a web app (without forcing the user to download heavy video files) is using CSS 2.5D Transformations.

This adds a realistic "breathing" effect and maps the movement directly to the biomechanics of the exercise (e.g., squatting goes down, bridging goes up).
